⚡ BOTW | The Cyber-Dark Messaging Engine
Stop copy-pasting. Start injecting.
BOTW is a high-fidelity Command Center designed to automate massive catalog distribution across WhatsApp networks. Built for high-velocity retail, it turns hours of manual messaging into a single-click operation.

🕹️ The Dashboard Experience
This isn't just another CRUD. It's a cockpit.

Cyber-Dark UI: A precision-engineered interface using Glassmorphism, neon-cyan accents, and optimized for 1600px ultra-wide monitoring.

Dynamic Payload Injection: Create, edit, and "prime" product cards (shoes, clothing, tech) with real-time visual previews.

Core Engine v3.0 (BotBox): Full control over transmission frequency (3s-60s) with live queue monitoring and "Engine Standby" signals.

🚀 Key Engineering Pillars
📦 Smart Diffusion Containers
Inventory is messy; BOTW is not. Group your products into logical "Diffusion Boxes" (e.g., New Arrivals, Flash Sale). Toggle entire collections on/off with a single switch.

📋 Precision Channel Targeting
Our Group Selector isn't a simple dropdown. It's a dedicated management layer to filter, select, and verify destination channels before firing a single byte.

⚡ Performance-First Architecture
State-Sync: Real-time synchronization between the FastAPI backend and React frontend.

Media Optimization: Cloudinary-ready pipeline for high-speed image delivery.

UX Flow: Zero-clutter navigation with horizontal scroll-snapping for massive inventories.

🧠 Solved Technical Challenges (The "Senior" Stuff)
Layering Logic: Solved complex z-index collisions between dynamic card overlays and global UI elements.

Information Density: Engineered a layout that displays 100+ items without losing operational clarity.

Anti-Spam Pacing: Implemented a customizable throttling engine to ensure delivery without triggering rate limits.
